Architecture decisions live under [`docs/adr`](https://github.com/chenxin-yan/mitome/tree/main/docs/adr). An accepted decision describes the target, which is not always built yet: the [MVP plan](https://github.com/chenxin-yan/mitome/blob/main/docs/plans/mvp-plan.md) says what is implemented and what comes after, and the [library plan](https://github.com/chenxin-yan/mitome/blob/main/docs/plans/effect-native-library.md) owns unresolved contracts and proof gates.

| Decision                                                                                                                                                                            | Meaning                                                                                                                                                                                                                                                                            |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [An Agent as data, run through a Configuration](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0058-describe-an-agent-as-data-and-run-it-through-a-configuration.md)      | `Agent.make` and `Extension.make` describe; `Mitome.make` names the Providers and Model. Implemented without Model Context shaping and events.                                                                                                                                     |
| [The Host answers Approvals](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0059-let-the-host-answer-approvals.md)                                                        | The `Approver` comes from the Host; with nobody present an ask is denied and the Model is told. The interaction service is not built yet.                                                                                                                                          |
| [One Configuration, logins outside it](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0060-load-one-configuration-and-keep-logins-out-of-it.md)                           | `mitome` loads the config directory's `index.ts` or `--config`; logins live in the state directory. `mitome init` writes the default Configuration; `npm create mitome` writes an application, not a Configuration. Running a Configuration does not install its dependencies yet. |
| [One package with a gated core](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0061-ship-one-package-and-gate-what-enters-its-core.md)                                    | `@mitome/core` holds the core; `session/` never imports `agent/`. Providers, the CLI and `create-mitome` are separate packages.                                                                                                                                                    |
| [Stream for display only](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0062-stream-for-display-only.md)                                                                 | Accepted, not implemented: a Step waits for the whole response.                                                                                                                                                                                                                    |
| [Anthropic sign-in through the Console profile](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0063-sign-in-to-anthropic-through-the-console-profile.md)                  | Accepted, not implemented: the Anthropic Provider takes an API key; reading the profile `ant auth login` writes comes later.                                                                                                                                                       |
| [Effect-native functions and optional Host composition](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0057-use-effect-native-functions-and-optional-host-composition.md) | Ordinary Effect programs, native Tool, Toolkit and Layer types, and whole-function Turns; amended by ADR-0058 to ADR-0061.                                                                                                                                                         |
| [History, Compaction and execution recovery](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0056-separate-history-compaction-and-execution-recovery.md)                   | Full replacement requires restart recovery and History trees; no arbitrary Effect replay or exactly-once external effects.                                                                                                                                                         |
| [Explicit persistence](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0040-compose-transcript-persistence-explicitly.md)                                                  | User composition owns storage; a Host never silently creates it.                                                                                                                                                                                                                   |
| [Agent-author Approval policy](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0051-let-the-agent-author-decide-tool-approvals.md)                                         | Fail-closed policy and authorized Approval are separate from replay safety.                                                                                                                                                                                                        |
| [Curated exports](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0047-curate-entry-points-by-audience.md)                                                                 | Keep explicit public boundaries; no parallel Promise agent API.                                                                                                                                                                                                                    |
| [Exact Effect pin](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0046-pin-effect-as-a-regular-dependency-during-rc.md)                                                   | Effect is an exact regular dependency; revisiting it for a stable Effect 4 is still open.                                                                                                                                                                                          |
| [Hand-authored API reference](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0052-author-the-api-reference-with-fumadocs-typescript.md)                                   | Reference pages are written by hand from verified implementation; none exist yet.                                                                                                                                                                                                  |

An amended ADR names its successors.
