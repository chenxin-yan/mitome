Architecture decisions live under [`docs/adr`](https://github.com/chenxin-yan/mitome/tree/main/docs/adr). Accepted target policy is not evidence that an API is shipped: the current implementation remains Promise-facing. The [library plan](https://github.com/chenxin-yan/mitome/blob/main/docs/plans/effect-native-library.md) owns unresolved contracts and proof gates; [#174](https://github.com/chenxin-yan/mitome/issues/174) owns delivery.

| Decision                                                                                                                                                                            | Meaning                                                                                                                    |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| [Effect-native functions and optional Host composition](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0057-use-effect-native-functions-and-optional-host-composition.md) | Accepted target; concrete Session/Turn/Host signatures are pending, not exports.                                           |
| [History, Compaction and execution recovery](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0056-separate-history-compaction-and-execution-recovery.md)                   | Full replacement requires restart recovery and History trees; no arbitrary Effect replay or exactly-once external effects. |
| [Explicit persistence](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0040-compose-transcript-persistence-explicitly.md)                                                  | User composition owns storage; a Host never silently creates it.                                                           |
| [Agent-author Approval policy](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0051-let-the-agent-author-decide-tool-approvals.md)                                         | Fail-closed policy and authorized consent are separate from replay safety.                                                 |
| [Curated exports](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0047-curate-entry-points-by-audience.md)                                                                 | Keep explicit public boundaries; no parallel Promise agent API in the target.                                              |
| [Effect RC pin](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0046-pin-effect-as-a-regular-dependency-during-rc.md)                                                      | Match exact Effect identity while the release-candidate rule applies.                                                      |
| [Hand-authored API reference](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0052-author-the-api-reference-with-fumadocs-typescript.md)                                   | New reference pages return alongside verified native implementation, not proposed signatures.                              |

Fully obsolete prerelease decisions and API guides are deleted; Git history preserves them. Mixed decisions retain their useful invariants with explicit amendments. This cleanup does not alter production code or establish any target durability guarantee.
