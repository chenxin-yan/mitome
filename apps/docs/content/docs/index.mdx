Mitome gives an Agent a typed Provider, a Default Model, Extensions, and one or more ways to run Sessions. Start with the Promise-first SDK; move to the Effect-native surface only when your application already composes Effect services and Layers.

## Start here

- [Quickstart](/docs/quickstart): initialize, authenticate, and open an interactive Session.
- [SDK](/docs/sdk): embed an Agent and consume the Turn event stream.
- [Extensions](/docs/extensions): add Tools, lifecycle Hooks, and Resources.
- [Transcript persistence](/docs/persistence): choose whether and where committed messages are stored.
- [CLI](/docs/cli) and [TUI](/docs/tui): run a trusted Mitome Definition from a terminal.
- [Providers](/docs/providers): configure OpenAI, Codex, or an OpenAI-compatible endpoint.
- [Effect](/docs/effect): use the supported Effect-native facade.
- [Host and Provider authoring](/docs/core): build integration packages against Effect-native Core contracts.

## Public packages

Application code imports from `@mitome/sdk`, Provider subpaths under `@mitome/providers`, and first-party Extensions from `@mitome/sdk/extensions`. Effect-native applications use the curated `@mitome/sdk/effect` facade. Only Host and Provider authors should import runtime plumbing from `@mitome/core`.
