Mitome is a TypeScript library and command line for user-defined AI Agents, built on Effect.

**Prerelease, and nothing is published to npm yet.** The packages below have build and test targets in the [repository](https://github.com/chenxin-yan/mitome), and any of them may still change. Until a release, the install commands on these pages do not work: `npm install -g @mitome/cli` and `npm create mitome` find nothing, and neither does the install `mitome init` runs.

## Two ways to start

**An Agent in the terminal.** Install the command, write the default Configuration, sign in and open it:

```sh
npm install -g @mitome/cli
mitome init                         # asks for a Provider and Model, writes the default Configuration
export OPENAI_API_KEY="your key"    # or the sign-in mitome init prints for your Provider
mitome
```

See [`mitome init`](/docs/cli#init) and [Agents and Configurations](/docs/agents#a-configuration).

**An application that embeds an Agent.** Scaffold a project that uses Mitome as a library (with Node.js 24.2 or later):

```sh
npm create mitome my-app
```

It writes `src/agent.ts` and `src/main.ts`, which runs the Agent with `Session.make(agent)`; its README says how to set the credential and run it. It writes no Configuration and does not use the `mitome` command. See [Embed an Agent in an application](/docs/agents#embed-an-agent-in-an-application).

## What is implemented

Implemented today, in one process:

- `@mitome/core`: describe an Agent as data with `Agent.make` and `Extension.make`, name it with its Providers and Model in a Configuration with `Mitome.make`, and run it with `Session.make(agent)`. See [Agents and Configurations](/docs/agents).
- `@mitome/providers`: OpenAI, OpenAI-compatible, OpenAI Codex (ChatGPT) and Anthropic (API key or Claude Console sign-in) Providers.
- `@mitome/cli`: `mitome init` writes the default Configuration; the `mitome` command opens a Configuration in the terminal, where Approvals are answered with `y` or `n`, an Extension's Commands run as `/name` and the keys are the Configuration's own, and `mitome run` runs it once without an Approver, so with the default program an ask is denied. See [CLI](/docs/cli).
- `@mitome/transcripts`: keeps a Configuration's conversations in files, so `mitome --continue` picks one up again. Without it history stays in memory. See [Keep history](/docs/agents#keep-history).
- `create-mitome`: `npm create mitome` writes an application that embeds an Agent.

Not yet: streaming output, continuing a Turn interrupted by a crash, `mitome serve` and Channels, and first-party Extensions such as coding Tools, Skills and MCP. The [MVP plan](https://github.com/chenxin-yan/mitome/blob/main/docs/plans/mvp-plan.md) lists what comes next; the [library plan](https://github.com/chenxin-yan/mitome/blob/main/docs/plans/effect-native-library.md) records the longer-term direction and its open contracts.

See also [Design decisions](/docs/design-decisions), [Security](/docs/security), [Versioning](/docs/versioning) and [Contributing](/docs/contributing). Shared vocabulary lives in the repository's [CONTEXT.md](https://github.com/chenxin-yan/mitome/blob/main/CONTEXT.md).
