Mitome runs a user-authored **Definition**: exactly one Agent's instructions, Model, and ordered Plugins. The default surface is `@mitome/sdk`; it is Promise-first and creates the same canonical values consumed by Core and the CLI.

## Initialize and authenticate

Mitome targets Bun. Install the CLI, then let it create a config-backed SDK Definition:

```sh
bun add -g @mitome/cli
mitome init
# Enter gpt-5.4-mini and an OpenAI API key when prompted.
mitome
```

`mitome init` writes `$XDG_CONFIG_HOME/mitome/agent.ts` (or `~/.config/mitome/agent.ts`), its exact dependencies, and the API key (entered with masked echo) in that config directory's `.env` with mode 0600. To change or rotate the saved API key later, run `mitome auth login`. `mitome` then opens an interactive Session: type a message, read streamed output, and send EOF to leave it.

The interactive loop streams model output until EOF.

<include>./examples/quickstart.ts#interactive</include>

Use `mitome --use /absolute/path/to/agent.ts` to run an explicit trusted Definition instead of the config default. See [OpenAI setup](/docs/providers/openai) for API-key details and [credentials and persistence](/docs/security) before sharing a Definition.
