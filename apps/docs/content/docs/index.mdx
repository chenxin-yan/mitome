Mitome is a TypeScript library and CLI/TUI for user-defined AI Agents.

**The Effect-native redesign is accepted, not complete.** The Promise-facing SDK, Agent Definitions, Extensions and their Hosts have been removed without a compatibility surface. Implemented today: native Sessions, Turns and controlled Steps, first-party Providers, process-local [applications](/docs/applications) composed with `defineMitome`, and the [CLI](/docs/cli) with one-shot `run` and the standalone `tui`. Persistence, attached TUI and HTTP Hosts are not implemented yet.

The [canonical library plan](https://github.com/chenxin-yan/mitome/blob/main/docs/plans/effect-native-library.md) separates accepted direction, open contracts and dependency-ordered proof/implementation gates. [ADR-0057](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0057-use-effect-native-functions-and-optional-host-composition.md) records the architecture; [roadmap #174](https://github.com/chenxin-yan/mitome/issues/174) tracks delivery.

The target is plain Effect agent functions with explicit scoped Sessions, whole-function Turns, native infrastructure and Tool types, and optional Host composition. TUI and mountable HTTP come first; messaging integrations come later. The full replacement still requires durable recovery, History trees, Compaction, Skills, controls and subagents. A process-local demo is an internal proof, not a smaller public release or a durability guarantee.
