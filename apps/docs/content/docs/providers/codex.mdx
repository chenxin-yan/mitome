> **Warning:** `@mitome/providers/openai-codex` uses OpenAI's unofficial, undocumented ChatGPT service endpoint. Compatibility is best effort: the service can change without notice, and this Provider carries a higher breakage risk than the [official OpenAI Provider](/docs/providers/openai).

The Codex Provider authenticates with a ChatGPT subscription login and streams over SSE. It is not `openai()` with another `baseUrl`, and an OpenAI API key does not work with it.

```ts
import { defineAgent } from "@mitome/sdk";
import { codex } from "@mitome/providers/openai-codex";

const agent = defineAgent({
  providers: [codex()],
  model: "openai-codex/gpt-5.4-mini",
});
```

The Provider id is `openai-codex`. `knownModelIds` lists the Models documented for Codex; other ids under `openai-codex/` are passed through and judged by the service.

## Authenticate

Choose **OpenAI Codex (ChatGPT)** during `mitome init`, or authenticate an existing Mitome Definition:

```sh
mitome auth login
```

Login opens your browser for a PKCE OAuth flow. If the browser cannot return to the CLI, paste the redirect URL at the prompt; set `MITOME_NO_BROWSER=1` to skip opening a browser and go straight to that prompt. The resulting OAuth Credential (access token, refresh token, expiry, account id) is stored under the `openai-codex` entry of `<config-dir>/auth.json`.

```sh
mitome auth logout
```

Logout removes only the Codex entry; other Providers' entries in `auth.json` stay.

The Provider refreshes the Credential on its own: an expired token is renewed before a request, and a request rejected with `401` triggers one refresh and retry. Refreshes are serialized across processes, so two Sessions never burn the same refresh token. You only log in again when the refresh token itself has been revoked.

## Embedded use

An application can use `codex()` too; it reads `auth.json` from the Mitome config directory, or from `configDirectory` if you pass one:

```ts
const provider = codex({ configDirectory: "/srv/agent/config" });
```

The config directory must resolve, or the Provider cannot find its Credential. `login()` and `logout()` are exported for applications that want to run the OAuth flow themselves; `mitome auth` is the usual way.

Treat `auth.json` as a secret: keep it out of version control, logs, and Instructions. The [Configuration](/docs/configuration#credentials) page lists every file and its permissions.
