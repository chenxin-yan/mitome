`@mitome/sdk/effect` is for applications that already run on Effect. It exposes the same [Agent](/docs/concepts#agent), [Extension](/docs/concepts#extension), and [Session](/docs/concepts#session) contracts as `@mitome/sdk`, with Effect, Stream, Layer, and Schema types instead of Promises and Standard Schema. Both surfaces run the same Session behavior, and Extensions from either may sit in one Agent Definition.

Choose it when you want a typed failure channel, Stream composition, or Extension Resources that are services in a Layer. For ordinary application code, the [Promise SDK](/docs/sessions) is shorter.

## Install

`@mitome/sdk` pins an exact Effect release candidate. Your application must use that same version, or Effect's runtime and types will not match across the boundary:

```sh
npm install @mitome/sdk @mitome/providers
npm ls effect
```

Install `effect` at exactly the version `npm ls` reports for `@mitome/sdk`.

## A scoped Session

`createSession` needs a `Scope`. Closing the Scope runs the `sessionEnd` Hooks and releases every Extension Resource.

```ts
import { Effect, Stream } from "effect";
import { createSession, defineAgent } from "@mitome/sdk/effect";
import { openai } from "@mitome/providers/openai";

const agent = defineAgent({
  providers: [openai()],
  model: "openai/gpt-5.4-mini",
});

const program = Effect.scoped(
  Effect.gen(function* () {
    const session = yield* createSession(agent);
    yield* Stream.runForEach(session.runTurn("Write a haiku."), (event) =>
      event.type === "model-output"
        ? Effect.sync(() => process.stdout.write(event.text))
        : event.type === "approval-required"
          ? event.approve()
          : Effect.void,
    );
  }),
);

await Effect.runPromise(program);
```

`session.runTurn()` returns a `Stream<TurnEvent, ...>`. Consume or interrupt it exactly once per Turn; interrupting the Stream interrupts the Turn and leaves the Session usable. The event variants are the ones the [Sessions](/docs/sessions) page lists, with `approve()` and `deny(reason?)` returning Effects. `createSession` accepts the same `{ transcripts }` and `{ transcript }` options as `withSession`; see [Persistence](/docs/persistence).

## Typed failures

Nothing is thrown. `createSession` fails with `AgentDefinitionError` or `TurnError`, and `runTurn` fails with `SessionBusyError`, `SessionReleasedError`, `StoreError`, or `TurnError`. All are Schema-tagged, so `Effect.catchTag` recovers by name:

```ts
const recovered = program.pipe(
  Effect.catchTag("TurnError", (error) => Effect.logError(error.message)),
);
```

## An Effect-native Extension

`defineExtension` from this entry point takes a `resource` Layer, Hooks that are Effects, and an Effect `Toolkit` with Effect handlers. The Layer is built when the Session starts and released when its Scope closes, so `Effect.acquireRelease` inside `Layer.effect` is the way to own a client or a connection for exactly one Session.

```ts
import { Context, Effect, Layer, Schema } from "effect";
import { Tool, Toolkit } from "effect/unstable/ai";
import { defineExtension } from "@mitome/sdk/effect";

class Notes extends Context.Service<Notes, { readonly values: Array<string> }>()("app/Notes") {}

const notesLayer = Layer.effect(
  Notes,
  Effect.acquireRelease(
    Effect.sync(() => ({ values: [] as Array<string> })),
    (notes) => Effect.sync(() => notes.values.splice(0)),
  ),
);

const saveNote = Tool.make("save_note", {
  description: "Save one note for this Session",
  parameters: Schema.Struct({ text: Schema.String }),
  success: Schema.String,
  dependencies: [Notes],
});

export const notes = defineExtension({
  name: "notes",
  instructions: "Save a note when the user asks you to remember something.",
  resource: notesLayer,
  toolkit: Toolkit.make(saveNote),
  handlers: {
    save_note: ({ text }: { readonly text: string }) =>
      Effect.gen(function* () {
        const store = yield* Notes;
        store.values.push(text);
        return `Saved ${store.values.length} note(s)`;
      }),
  },
  hooks: {
    sessionEnd: Effect.gen(function* () {
      const store = yield* Notes;
      yield* Effect.log(`Session ended with ${store.values.length} note(s)`);
    }),
    preTool: ({ name }) =>
      Effect.succeed(name === "save_note" ? undefined : { reason: `${name} is not allowed` }),
  },
});
```

The pieces map onto the Promise surface like this:

| Promise SDK                           | Effect API                                                                      |
| ------------------------------------- | ------------------------------------------------------------------------------- |
| `setup` / `dispose` returning a value | `resource`: a `Layer` whose services Hooks and handlers `yield*`                |
| `tools: ({ tool }) => [...]`          | `toolkit: Toolkit.make(...)` plus a `handlers` record keyed by Tool name        |
| `inputSchema` / `outputSchema`        | `parameters` / `success` on `Tool.make`; `failure` declares an expected failure |
| `needsApproval`                       | `needsApproval` on `Tool.make`                                                  |
| Promise Hooks with `{ resource }`     | Hooks that are Effects requiring the Resource service                           |

A Tool whose `dependencies` or handler need a service that the `resource` Layer does not provide is rejected at the type level. The Hook names and their contracts are the same as on the [Extensions](/docs/extensions#hooks) page; a failing Hook fails the Turn with `TurnError`.

## Effect Transcript stores
