The [API reference](/docs/reference/api) is generated from the TSDoc comments on each public export, one page per import path:

- [`@mitome/sdk`](/docs/reference/api/sdk), [`@mitome/sdk/effect`](/docs/reference/api/sdk-effect), and [`@mitome/sdk/extensions`](/docs/reference/api/sdk-extensions) for application code.
- [`@mitome/core`](/docs/reference/api/core) for Host and Provider authors.
- [`@mitome/providers/openai`](/docs/reference/api/providers-openai), [`@mitome/providers/openai-compatible`](/docs/reference/api/providers-openai-compatible), and [`@mitome/providers/openai-codex`](/docs/reference/api/providers-openai-codex).
- [`@mitome/tui`](/docs/reference/api/tui).

Two hand-written tables complete it:

- [CLI reference](/docs/reference/cli): every command, flag, environment variable, and exit status of `mitome`.
- [Errors](/docs/reference/errors): each error class with its cause and remedy, and the CLI messages you will see.
