Curated Effect-native application surface: the same Agent, Extension, and Session contracts as
`@mitome/sdk` with Effect, Stream, Layer, and Schema types exposed.

## Interfaces

### ChannelHost

A Host that connects an external surface to the Agent. It must expose `handle`, `serve`, or both;
[`defineMitome`](#definemitome) rejects a Channel Host with neither. `mitome [message]` ignores
Channel Hosts; `mitome serve` runs them.

<auto-type-table path="../../../../../../packages/sdk/src/effect.ts" name="ChannelHost" />

### ChannelHostContext

What a Channel Host receives to run Sessions for one Mitome Definition. Extended by
[`HostContext`](#hostcontext).

<auto-type-table path="../../../../../../packages/sdk/src/effect.ts" name="ChannelHostContext" />

### CreateSessionOptions

Persistence and seeding for [`createSession`](#createsession).

<auto-type-table path="../../../../../../packages/sdk/src/effect.ts" name="CreateSessionOptions" />

### ExtensionHooks

Effect-native lifecycle Hooks. Start Hooks run in Agent Definition order and end Hooks in reverse;
a failing Hook fails the Turn (or Session start) with [`TurnError`](/docs/reference/api/sdk#turnerror).
`Resource` is the Extension's Resource type (default `never`); every Hook may require it.

<auto-type-table path="../../../../../../packages/sdk/src/effect.ts" name="ExtensionHooks" />

### HostContext

What an interactive Host receives: the [`ChannelHostContext`](#channelhostcontext) plus the staged
first Message.

<auto-type-table path="../../../../../../packages/sdk/src/effect.ts" name="HostContext" />

### InteractiveHost

A Host that owns a TTY process, such as `@mitome/tui`. `mitome [message]` runs the first interactive
Host in Definition order whose `unsupported()` returns undefined and otherwise falls back to
one-shot output.

<auto-type-table path="../../../../../../packages/sdk/src/effect.ts" name="InteractiveHost" />

### MakeTranscriptOptions

Input to [`makeTranscript`](#maketranscript).

<auto-type-table path="../../../../../../packages/sdk/src/effect.ts" name="MakeTranscriptOptions" />

### MitomeDefinition

The composition root pairing one Agent Definition with its Hosts and Transcript persistence. A
Mitome Definition module exports it as default; [`defineMitome`](#definemitome) creates it. `Agent`
is the [`AgentDefinition`](/docs/reference/api/sdk#agentdefinition) type it was created with.

<auto-type-table path="../../../../../../packages/sdk/src/effect.ts" name="MitomeDefinition" />

### Session

A live, process-bound interaction with one Agent, obtained from [`createSession`](#createsession)
inside a Scope. `Providers` is the Agent's Provider tuple, which types the `model` override of
[`TurnOptions`](/docs/reference/api/sdk#turnoptions).

<auto-type-table path="../../../../../../packages/sdk/src/effect.ts" name="Session" />

### ToolContribution

Type-level record of one Tool's input, output, and expected failure types. Defaults are
[`ToolInput`](#toolinput), [`ToolOutput`](#tooloutput), and `never`.

<auto-type-table path="../../../../../../packages/sdk/src/effect.ts" name="ToolContribution" />

### ToolHookContext

The Tool call a `preTool` Hook observes. Extended by [`ToolResultHookContext`](#toolresulthookcontext).

<auto-type-table path="../../../../../../packages/sdk/src/effect.ts" name="ToolHookContext" />

### ToolResultHookContext

The Tool result a `postTool` Hook observes; `isFailure` marks an expected failure value.

<auto-type-table path="../../../../../../packages/sdk/src/effect.ts" name="ToolResultHookContext" />

### TranscriptStore

Effect-native persistence contract. Sessions call `save` and `appendEvent`; Hosts call `load` and
`list` to resume. Adapters own their concurrency policy: concurrent resumes are independent forks.
Operations fail with [`StoreError`](/docs/reference/api/sdk#storeerror); `load` also fails with
[`TranscriptNotFound`](/docs/reference/api/sdk#transcriptnotfound).

<auto-type-table path="../../../../../../packages/sdk/src/effect.ts" name="TranscriptStore" />

[`InteractiveHost`](#interactivehost) and [`ChannelHost`](#channelhost).

### ToolResultValidator

```ts
type ToolResultValidator = (result: ToolOutput) => Effect.Effect<ToolOutput, unknown>;
```

Revalidates a successful Tool result, including after `postTool` transforms.

### TurnEvent

```ts
type TurnEvent =
  | { readonly type: "model-output"; readonly text: string }
  | { readonly type: "reasoning"; readonly text: string }
  | {
      readonly type: "tool-call";
      readonly id: string;
      readonly name: string;
      readonly params: unknown;
    }
  | {
      readonly type: "tool-result";
      readonly id: string;
      readonly name: string;
      readonly result: unknown;
      readonly isFailure: boolean;
    }
  | {
      readonly type: "approval-required";
      readonly approvalId: string;
      readonly toolCallId: string;
      readonly name: string;
      readonly params: unknown;
      readonly requirement: ApprovalRequirement;
      /** Lets the Tool call run. One-shot: resolving again or after the Turn ended fails. */
      readonly approve: () => Effect.Effect<void, ApprovalResolutionError>;
      /** Rejects the Tool call; the Model sees `reason`. One-shot like `approve`. */
      readonly deny: (reason?: string) => Effect.Effect<void, ApprovalResolutionError>;
    }
  | {
      readonly type: "response-complete";
      readonly finishReason?: Response.FinishReason | undefined;
      readonly usage?: Response.Usage | undefined;
    };
```

One event emitted while a Turn runs. `approval-required` pauses the Turn until `approve` or `deny`
resolves; `response-complete` is the final event of a successful Turn and is emitted only after the
Transcript save succeeded. `requirement` is an
[`ApprovalRequirement`](/docs/reference/api/sdk#approvalrequirement); `approve` and `deny` fail with
[`ApprovalResolutionError`](/docs/reference/api/sdk#approvalresolutionerror). `Response` is
`effect/unstable/ai`'s Response module.

## Variables

### createSession

```ts
const createSession: <const Definition extends AgentDefinition>(
  definition: Definition,
  options?: CreateSessionOptions,
) => Effect.Effect<Session<ProvidersOf<Definition>>, AgentDefinitionError | TurnError, Scope.Scope>;
```

Compiles the Agent Definition, acquires Extension Resources, and runs `sessionStart` Hooks. The
Session lives until the enclosing Scope closes, which runs `sessionEnd` Hooks and releases Resources
in reverse Agent Definition order. `ProvidersOf<Definition>` is the Definition's Provider tuple.

Returns a [`Session`](#session) in a `Scope`, failing with
[`AgentDefinitionError`](/docs/reference/api/sdk#agentdefinitionerror) or
[`TurnError`](/docs/reference/api/sdk#turnerror).

### defineMitome

```ts
const defineMitome: <const Agent extends AgentDefinition>(
  definition: Omit<MitomeDefinition<Agent>, "hosts"> & { readonly hosts?: ReadonlyArray<Host> },
) => MitomeDefinition<Agent>;
```

Creates a Mitome Definition. `hosts` defaults to none and may hold any number of Hosts. A value that
is not a Host (typically a factory that was not called), an unknown `kind`, a Channel Host without
`handle` or `serve`, a Channel Host named `.` or `..` or with a lone surrogate in its name, or two
Channel Hosts sharing a name throws with the offending Host named.

Returns a [`MitomeDefinition`](#mitomedefinition).

### fileTranscripts

```ts
const fileTranscripts: (directory?: string) => TranscriptStore;
```

Creates a disk-backed store rooted at `directory` or the Mitome config directory.

Returns a [`TranscriptStore`](#transcriptstore).

### makeTranscript

```ts
const makeTranscript: (input: MakeTranscriptOptions) => Transcript;
```

Encodes Model Prompt messages into a Transcript. Throws when a message cannot be represented, so the
Transcript never silently loses data.

Returns a [`Transcript`](/docs/reference/api/sdk#transcript).

### memoryTranscripts

In-memory store for tests or a shared store without disk writes. Contents live as long as the
returned value; event records are discarded.

Returns a [`TranscriptStore`](#transcriptstore).

```ts
const summarizeTranscript: (
```

### TranscriptEventRecordSchema

```ts
const TranscriptEventRecordSchema: Schema.Struct<{
  transcriptId: Schema.String;
  sessionId: Schema.String;
  seq: Schema.Natural;
  version: Schema.Literal<1>;
  event: typeof TurnEventDtoSchema;
}>;
```

Records decode independently. A tail without `response-complete` is not a corrupt log: the Turn was
interrupted, or committed and then failed to append its final record. Event records are
observability data and have no Session replay contract; the Transcript snapshot is authoritative.
Its `Type` is [`TranscriptEventRecord`](/docs/reference/api/sdk#transcripteventrecord).

### TranscriptEventRecordVersion

```ts
const TranscriptEventRecordVersion: 1;
```

The `version` written into every event record this version of Mitome produces.

### TranscriptMessageSchema

```ts
const TranscriptMessageSchema: Schema.Codec<TranscriptMessage>;
```

Schema of one committed Message; file data is stored as a string, base64, or URL. A `Schema.Union`
of four `Schema.Struct` members discriminated by `role` (`"system"`, `"user"`, `"assistant"`,
`"tool"`), each with its `content` and optional Provider `options`. Its `Type` is
[`TranscriptMessage`](/docs/reference/api/sdk#transcriptmessage).

### TranscriptSchema

```ts
const TranscriptSchema: Schema.Struct<{
  schemaVersion: Schema.Literal<1>;
  id: Schema.String;
  parentTranscriptId: Schema.optional<Schema.String>;
  messages: Schema.$Array<typeof TranscriptMessageSchema>;
}>;
```

Schema of a Transcript. Stored bytes are a trust boundary: store adapters decode with it before
returning a Transcript. Its `Type` is [`Transcript`](/docs/reference/api/sdk#transcript).

### TranscriptSummarySchema

```ts
const TranscriptSummarySchema: Schema.Struct<{
  id: Schema.String;
  parentTranscriptId: Schema.optional<Schema.String>;
  createdAt: Schema.String;
  updatedAt: Schema.String;
  messageCount: Schema.Natural;
  preview: Schema.String;
}>;
```

Schema of one `TranscriptStore.list` row. Its `Type` is
[`TranscriptSummary`](/docs/reference/api/sdk#transcriptsummary).

### TurnEventDtoSchema

```ts
const TurnEventDtoSchema: Schema.Codec<TurnEventDto>;
```

Schema of the serializable Turn event persisted through `TranscriptStore.appendEvent`. A
`Schema.Union` of seven `Schema.Struct` members discriminated by `type`: `"model-output"`,
`"reasoning"`, `"tool-call"`, `"tool-result"`, `"approval-required"`, `"approval-resolved"`, and
`"response-complete"`. Its `Type` is [`TurnEventDto`](/docs/reference/api/sdk#turneventdto).

## Functions

### defineAgent

```ts
function defineAgent<
  const Providers extends ReadonlyArray<unknown>,
  const DefaultModel extends QualifiedModelId<Extract<NoInfer<Providers[number]>, AnyProvider>>,
>(definition: {
  readonly providers: Providers;
  readonly model: DefaultModel;
  readonly extensions?: undefined;
  readonly approvals?: ApprovalPolicy | undefined;
}): AgentDefinition<Extract<Providers, ReadonlyArray<AnyProvider>>, DefaultModel, readonly []>;

function defineAgent<
  const Providers extends ReadonlyArray<unknown>,
  const DefaultModel extends QualifiedModelId<Extract<NoInfer<Providers[number]>, AnyProvider>>,
  const Extensions extends ReadonlyArray<AnyExtension>,
>(definition: {
  readonly providers: Providers;
  readonly model: DefaultModel;
  readonly extensions: Extensions;
  readonly approvals?: ApprovalPolicy<NoInfer<Extensions>> | undefined;
}): AgentDefinition<Extract<Providers, ReadonlyArray<AnyProvider>>, DefaultModel, Extensions>;
```

Declares an Agent from its Providers, Default Model, and optional Extensions. The Default Model is
checked against the registered Providers' catalogs at the type level while still accepting any
`provider/model` id for a registered Provider, because catalogs are hints, not allow-lists. Both
overloads also reject, at the type level, a `providers` tuple whose members are not all
[`AnyProvider`](/docs/reference/api/sdk#anyprovider). The second overload declares an Agent with
Extensions and types `approvals` against them.

Returns an [`AgentDefinition`](/docs/reference/api/sdk#agentdefinition).

### defineExtension

```ts
function defineExtension<const LayerValue extends Layer.Layer<any, any, never>>(
  extension: ToolkitlessExtension<LayerValue> & { readonly resource: LayerValue },
): Extension<Layer.Success<LayerValue>, Layer.Error<LayerValue>>;

function defineExtension(extension: ResourceFreeToolkitlessExtension): Extension;

function defineExtension<const ToolkitValue extends Toolkit.Any>(
  extension: ToolkitExtension<ToolkitValue>,
): Extension<never, never, ToolkitContributions<Toolkit.ToolsByName<Toolkit.Tools<ToolkitValue>>>>;

function defineExtension<
  const LayerValue extends Layer.Layer<any, any, never>,
  const ToolkitValue extends Toolkit.Any,
>(
  extension: ResourcefulToolkitExtension<LayerValue, ToolkitValue>,
): Extension<
  Layer.Success<LayerValue>,
  Layer.Error<LayerValue>,
  ToolkitContributions<Toolkit.ToolsByName<Toolkit.Tools<ToolkitValue>>>
>;
```

Declares an [`Extension`](/docs/reference/api/sdk#extension). Each overload accepts the fields of
`Extension` with one combination of `resource` and `toolkit`; the parameter types name those
combinations and are not exported:

- Resource `Layer`, no Tools: Hooks use the Resource. The Layer is built when a Session starts and
  released, in reverse order, when its scope closes.
- Neither Resource nor Tools: Instructions and Hooks only.
- Effect `Toolkit`, no Resource: every Tool needs a handler, and handlers may not require services
  the Extension does not provide.
- Resource `Layer` and `Toolkit`: Toolkit handlers and Hooks share one Resource. Service requirements
  the Layer does not satisfy are rejected at the type level.

A `LayerValue` typed `any` is rejected at the type level in the overloads that take one.
