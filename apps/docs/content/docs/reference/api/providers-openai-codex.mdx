### LoginOptions

Options for `login`: Host I/O callbacks plus the directory that will hold `auth.json`. The I/O
callbacks (`input`, `output`, `openBrowser`) and the OAuth overrides (`callbackPort`, `tokenUrl`)
come from the shared PKCE login contract; `configDirectory` is Codex-specific.

```ts

  readonly type: "oauth";
  readonly access: string;
  readonly refresh: string;
```

The stored ChatGPT OAuth Credential: access and refresh tokens, expiry, and account id. This is
the decoded shape of the Codex entry in `auth.json`.

## Variables

### authenticate

```ts
const authenticate: AuthCapability["authenticate"];
```

Generic Host entry point satisfying Core's
[`AuthCapability`](/docs/reference/api/core#authcapability) contract. Dispatches on
`options.operation`: `"logout"` calls
[`logout`](/docs/reference/api/providers-openai-codex#logout), anything else calls
[`login`](/docs/reference/api/providers-openai-codex#login). The CLI reaches it through the
Provider's Credential descriptor, which names this module.

## Functions

### codex

```ts
function codex(options?: CodexOptions): Provider<"openai-codex", typeof knownModelIds>;
```

Creates the configured ChatGPT Codex Provider. Its Credential descriptor is a reference to this
module's Auth capability rather than an environment variable, so `mitome` can run the OAuth login
on the Provider's behalf.

Returns a [`Provider`](/docs/reference/api/sdk#provider) with id `"openai-codex"`.

### login

```ts
function login(options: LoginOptions): Promise<void>;
```

Runs Codex PKCE login and stores the resulting Credential in `auth.json` under
`options.configDirectory`.

### logout

```ts
function logout(options: LogoutOptions): Promise<void>;
```

Removes only the Codex Credential from `auth.json` under `options.configDirectory`; other
Providers' entries are untouched.
