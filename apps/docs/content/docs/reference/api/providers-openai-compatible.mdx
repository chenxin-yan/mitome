## Functions

### openaiCompatible

```ts
function openaiCompatible<const Id extends string>(
  options: OpenAiCompatibleOptions<Id> & { readonly id: ValidProviderId<Id> },
): Provider<ValidProviderId<Id>, readonly []>;
```

Creates a configured Provider for an OpenAI-compatible endpoint. `id` becomes the prefix of the
endpoint's Qualified Model ids, so it must be non-empty and contain no `/`
([`ValidProviderId`](/docs/reference/api/core#validproviderid) enforces this at the type level
and `makeProvider` at runtime; for a valid literal `ValidProviderId<Id>` is just `Id`). Trailing slashes on `baseUrl` are removed. When `apiKeyEnv` is
set, the key is read from the environment when a Session provisions a Model; when it is omitted,
requests carry no API key.

Returns a [`Provider`](/docs/reference/api/sdk#provider) with an empty Model catalog.
