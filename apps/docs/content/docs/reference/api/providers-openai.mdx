## Variables

### knownModelIds

```ts
const knownModelIds: readonly ["o4-mini", "o3-pro", "o3-mini", "o3", "o1-pro", "o1", ...];
```

Tool-capable OpenAI Model ids from models.dev, offered as completions; not a closed catalog. The
list is generated from a models.dev snapshot at build time, so the exact tuple follows the
installed version of the package.

## Functions

### openai

```ts
function openai(options?: OpenAiOptions): Provider<"openai", typeof knownModelIds>;
```

Creates the configured OpenAI Provider. `apiKeyEnv` defaults to `OPENAI_API_KEY` and `baseUrl` to
`https://api.openai.com/v1`; trailing slashes on `baseUrl` are removed. The API key is read from
the environment when a Session provisions a Model, not when the Provider is created; a missing or
empty variable fails that Turn with a [`TurnError`](/docs/reference/api/sdk#turnerror).

Returns a [`Provider`](/docs/reference/api/sdk#provider) with id `"openai"`.
