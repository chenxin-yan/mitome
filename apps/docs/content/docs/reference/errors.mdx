SDK errors are Schema-tagged classes exported from `@mitome/sdk` and `@mitome/sdk/effect`. Catch them with `instanceof` or by `_tag`; the pattern is shown under [Sessions](/docs/sessions#failures).

## Error classes

| Error                                                                        | Raised when                                                                                                                                                                                                                                                                                              | What to do                                                                                                                                                                                                                                                                                                  |
| ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`AgentDefinitionError`](/docs/reference/api/sdk#agentdefinitionerror)       | Opening a Session with an Agent Definition that does not compile: duplicate Provider ids, a Default Model whose prefix matches no Provider, two different Extensions sharing a name, a malformed `provider/model` id, duplicate Tool names, or a Tool handler without a matching Tool.                   | Read `issues`; each entry names one problem.                                                                                                                                                                                                                                                                |
| [`SessionBusyError`](/docs/reference/api/sdk#sessionbusyerror)               | `runTurn` while another Turn on the same Session is still running.                                                                                                                                                                                                                                       | Consume or interrupt the active Turn first; a Session runs one Turn at a time.                                                                                                                                                                                                                              |
| [`SessionReleasedError`](/docs/reference/api/sdk#sessionreleasederror)       | `runTurn` after `withSession` returned or the Effect Scope closed.                                                                                                                                                                                                                                       | Keep Turn code inside the callback or Scope. Do not let the Session escape it.                                                                                                                                                                                                                              |
| [`TurnError`](/docs/reference/api/sdk#turnerror)                             | The Model call, a Hook (`preTool`, `postTool`, start or end Hooks), or a Tool schema validator failed while completing a Turn. `message` says which; `cause` holds the original error. A thrown Tool handler is not a `TurnError`: the Model sees an opaque failed `tool-result` and the Turn continues. | The Turn is not committed and the Session stays usable. Fix the Hook or validator, or retry the Model call. How Tool handler errors surface is under [Tools](/docs/tools).                                                                                                                                  |
| [`StoreError`](/docs/reference/api/sdk#storeerror)                           | A Transcript store operation failed: the final `save`, an `appendEvent`, `load`, or `list`.                                                                                                                                                                                                              | After a failed `save` the Turn is absent from `history()` and `transcript()`; re-sending the Message re-runs the Model. After a failed `appendEvent` on the final event, the Turn is already committed; check `session.transcript()` before retrying. See [Persistence](/docs/persistence#commit-boundary). |
| [`TranscriptNotFound`](/docs/reference/api/sdk#transcriptnotfound)           | `resume: id` names a Transcript the store does not have.                                                                                                                                                                                                                                                 | List the store's Transcripts and pick an existing id; Transcript ids are per store.                                                                                                                                                                                                                         |
| [`ApprovalResolutionError`](/docs/reference/api/sdk#approvalresolutionerror) | `approve()` or `deny()` called a second time, or after the Turn ended (`reason: "not-pending"`).                                                                                                                                                                                                         | Resolve each `approval-required` event exactly once, while its Turn is running. See [Approvals](/docs/approvals).                                                                                                                                                                                           |

Plain `Error`s thrown outside a Turn:

| Thrown by                    | Message                                                                                                              | What to do                                                                           |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `defineMitome`               | `Mitome Definition must declare at most one Host.`                                                                   | Keep one entry in `hosts`.                                                           |
| `defineMitome`               | `Host must be an object with a run function and optional unsupported function — did you forget to call the factory?` | Write `hosts: [tui()]`, not `hosts: [tui]`.                                          |
| `fileTranscripts()`          | `Cannot configure file Transcript persistence. Set MITOME_HOME, XDG_CONFIG_HOME, APPDATA (on Windows), or HOME.`     | Set one of those variables, or pass a directory: `fileTranscripts("./transcripts")`. |
| `session.runTurn()` iterable | `session.runTurn() returns a single-use iterable; call runTurn() again to run a new Turn`                            | Iterate each `runTurn()` result once. To run again, call `runTurn()` again.          |

## CLI messages

Every failure exits with status 1 and prints a message to stderr; these are the common ones. Failures inside `bun install` or `bun remove` propagate Bun's own message and exit status.

| Message                                                                                                                                                | Cause                                                                                                | What to do                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `Set MITOME_HOME, XDG_CONFIG_HOME, APPDATA (on Windows), or HOME. Or use --use <path>.`                                                                | No config directory resolves and no `--use` was given.                                               | Set one of the variables; see [Configuration](/docs/configuration#the-config-directory).              |
| `No Mitome Definition found; run mitome init first or use --use <path>.`                                                                               | `<config-dir>/index.ts` does not exist.                                                              | Run `mitome init`, or point `--use` at your Mitome Definition.                                        |
| `Mitome Definition not found at <path>; check the --use path.`                                                                                         | The `--use` path does not exist.                                                                     | Fix the path.                                                                                         |
| `No Mitome Definition module found at <dir>/index.ts.`                                                                                                 | `--use` named a directory without an `index.ts`.                                                     | Add `index.ts` or name the module file directly.                                                      |
| `Mitome Definition path <path> must be a TypeScript module.`                                                                                           | `--use` named a file that is not `.ts`.                                                              | A Mitome Definition module is TypeScript.                                                             |
| `The selected module must default-export defineMitome({ agent, hosts }).`                                                                              | The module's default export is not a Mitome Definition.                                              | End the module with `export default defineMitome({ ... })`.                                           |
| `Missing argument message (one-shot output needs a message; interactive Sessions need a TTY without --print)`                                          | `-p` given, or stdout is not a TTY, and no `[message]` was passed.                                   | Pass a Message, or run in a terminal without `-p`.                                                    |
| `No @mitome/core is installed beside <path> ...` / `@mitome/core beside <path> is "<version>" ...`                                                     | The Mitome Definition's dependencies resolve a different `@mitome/core` than the CLI was built with. | Set `@mitome/core` in its `package.json` to the version the message names, then run `mitome install`. |
| `Agent Definition has no auth-capable Providers.`                                                                                                      | `auth login` on a Mitome Definition whose Providers need no Credential.                              | Nothing to log in to.                                                                                 |
| `Multiple auth-capable Providers; choose one interactively: <ids>`                                                                                     | `auth login` with several Providers and no TTY to prompt.                                            | Run it in a terminal.                                                                                 |
| `Credential value is required.`                                                                                                                        | Empty input at the API-key prompt.                                                                   | Paste the key.                                                                                        |
| `<NAME> contains characters Bun cannot store in .env ('#', '$', quotes, edge whitespace, or newlines); set the environment variable directly instead.` | The key cannot round-trip through `.env`.                                                            | Export it in your shell; see [Configuration](/docs/configuration#credentials).                        |
| `Invalid package specifier: <input>`                                                                                                                   | `mitome add` with a specifier that is not `name` or `name@version`.                                  | Use a plain package name, optionally with `@version`.                                                 |
| `Provider authentication failed.`                                                                                                                      | An OAuth login or logout flow exited with an error.                                                  | Re-run `mitome auth login`; `MITOME_NO_BROWSER=1` if a browser cannot open.                           |
| `Model ID is required.`                                                                                                                                | Empty custom Model id during `mitome init`.                                                          | Enter an id in `provider/model` form.                                                                 |
| `<path> already exists`                                                                                                                                | `mitome init` would overwrite a file.                                                                | Move or delete it; `init` never overwrites.                                                           |

Errors raised inside the running Agent are printed as `<Tag>: <message>` followed by an indented `cause:` line when there is one; they are the classes in the first table.
