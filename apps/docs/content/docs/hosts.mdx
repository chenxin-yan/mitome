A [Host](/docs/concepts#host) connects people to the Agent through one surface: it starts Turns, presents events, and resolves Approvals. `@mitome/tui` is one; the CLI's one-shot printer is another. This page is for authoring your own, against `@mitome/core`.

`@mitome/core` is Effect-native and exposes runtime plumbing, so it carries a weaker stability guarantee than `@mitome/sdk`. Application code should stay on the [Promise SDK](/docs/sessions) or the [Effect-native API](/docs/effect).

## The Host contract

`Host` is a union of two kinds, discriminated by `kind`.

### `kind: "interactive"`

An interactive Host owns a terminal for one person:

| Member                                | Contract                                                                                                                                    |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `run(context): Promise<void>`         | Runs Sessions for the context and resolves when the Host is finished. The CLI exits when it resolves.                                       |
| `unsupported?(): string \| undefined` | Returns a reason when the Host cannot run in the current environment, or `undefined` when it can. The CLI prints the reason and falls back. |

`run` receives a `HostContext`:

| Field         | Meaning                                                                                        |
| ------------- | ---------------------------------------------------------------------------------------------- |
| `agent`       | The Agent Definition from `defineMitome({ agent })`.                                           |
| `message`     | The first user Message from the command line, or `""` when the user gave none.                 |
| `transcripts` | The Effect `TranscriptStore` from `defineMitome({ transcripts })`, or `undefined` when absent. |

### `kind: "channel"`

A Channel Host connects an external surface such as a messaging service. It declares a `name`, unique among the Channel Hosts of one Mitome Definition, and at least one capability:

| Member                                                 | Contract                                                                                                    |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| `handle(context, request: Request): Promise<Response>` | Answers one request. The response body owns the Session scope until the body ends or is cancelled.          |
| `serve(context, signal: AbortSignal): Promise<void>`   | Runs a long-lived connection, such as polling, and resolves only after the signal aborts and shutdown ends. |

Both receive a `ChannelHostContext` with `agent` and `transcripts` and no `message`: a Channel gets its Messages from the surface it connects. `mitome [message]` validates Channel Hosts but does not serve them; a later command will.

Hosts never construct or discover a store; they use the one the Mitome Definition composed, so every Host resumes from the same place.

## A minimal Host

`createHostSession(context)` opens the scoped Session for a context. Closing the Scope ends the Session.

```ts
import { Effect, Stream } from "effect";
import { createHostSession, type InteractiveHost } from "@mitome/core";

export const printer = (): InteractiveHost => ({
  kind: "interactive",
  unsupported: () => (process.stdout.isTTY ? undefined : "printer needs a TTY"),
  run: (context) =>
    Effect.runPromise(
      Effect.scoped(
        Effect.gen(function* () {
          const session = yield* createHostSession(context);
          yield* Stream.runForEach(session.runTurn(context.message), (event) => {
            switch (event.type) {
              case "model-output":
                return Effect.sync(() => process.stdout.write(event.text));
              case "approval-required":
                return event.deny("This Host does not run Tools.");
              default:
                return Effect.void;
            }
          });
        }),
      ),
    ),
});
```

Export a factory such as `printer()` from your package so users declare it as `hosts: [printer()]`; a Host module owns its own options, so pass them to the factory rather than to `defineMitome`. `defineMitome` throws when given a factory that was not called, a Host with an unknown `kind`, a Channel Host with neither `handle` nor `serve`, or two Channel Hosts sharing a name; each message names the offending Host by index or name. The [Runner](/docs/concepts#host) repeats the same checks when `mitome` loads the Definition, so a hand-written default export gets the same messages.

## Approvals

Every `approval-required` event a Host receives must be resolved with `approve()` or `deny(reason?)`, or the Turn interrupted; an unresolved Approval leaves the Turn paused forever. A Host that puts a person in the loop presents `name` and `params` and waits. The built-in one-shot printer and the TUI approve automatically after `preTool` Hooks pass; the [Approvals](/docs/approvals) page explains the difference between policy and consent.

## How the CLI picks a Host

A Mitome Definition declares any number of Hosts. When `mitome` runs a Definition:

1. With `--print`/`-p`, or when stdout is not a TTY, it uses the built-in one-shot printer and ignores every declared Host. One-shot output needs a message and exits with an error without one.
2. Otherwise it walks the interactive Hosts in declaration order and calls each `unsupported()`. The first that returns `undefined` gets the context through `run`, and the process exits when `run` resolves.
3. When `unsupported()` returns a reason, the CLI writes `<reason>; trying the next Host.` to stderr, or `<reason>; falling back to one-shot output.` when it was the last interactive Host, and continues.
4. With no interactive Host left, it uses the one-shot printer. Channel Hosts are skipped.

Installing a Host package changes nothing until the Mitome Definition declares it. All of this runs inside the CLI's Runner process; see [Security](/docs/security) for what that process can reach.
