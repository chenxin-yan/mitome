Mitome runs user-authored code with the permissions of its process. The [redesign plan](https://github.com/chenxin-yan/mitome/blob/main/docs/plans/effect-native-library.md) is accepted direction, not an implemented security or durability guarantee.

## Trust executable modules

An explicitly selected composition module and its dependencies are executable code, not a sandboxed configuration file. Import only code you trust. Tool policy does not sandbox arbitrary Agent programs, infrastructure, or Hosts. Explicit module selection must not turn into implicit execution of project-local code.

## Separate policy, consent and replay safety

The Agent author controls policy; Tools flag risk and reusable policy may tighten it. Hosts resolve permitted asks, never override a deny. Missing consent or a policy failure must not silently permit execution. Decode Tool input before policy, validate declared outcomes, and keep defects and secrets out of Model-visible results.

Approval authorizes an operation, not a retry after a crash. An unknown unsafe external outcome requires reconciliation; cancellation cannot undo an effect already completed. Passive progress events are not authoritative Approval or commit records.

## Authenticate before accessing state

For external Channels, including HTTP, authenticate and authorize before Route/history/model access. Conversation, Turn and Approval ids are not credentials. Approval, cancellation and result retrieval must enforce ownership, including after reconnect. Persisted state and incoming payloads are untrusted boundaries and must be decoded.

## Protect Credentials and stored data

Keep secrets out of source, Instructions, Tool outputs, thrown errors, logs, and bug reports. Do not commit `.env` or `auth.json`. Embedded applications supply credentials through their own environment or secret manager; CLI-only environment loading must not override explicit process values.

Retain private credential file permissions, atomic writes, refresh locking and per-Provider isolation from [ADR-0010](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0010-persist-provider-credentials-outside-the-environment.md) and [ADR-0031](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0031-share-oauth-and-credential-storage-across-provider-subpaths.md). Transcripts and execution/delivery records can contain user data, Tool inputs and results; storage retention/access policies require explicit ownership. The new backend and crash guarantees remain design work, not claims derived from today's Transcript files.
