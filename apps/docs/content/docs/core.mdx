`@mitome/core` is the Effect-native authoring surface for Host and Provider packages. Application code should use [`@mitome/sdk`](/docs/sdk) or its curated [`/effect` facade](/docs/effect); Core exposes runtime plumbing and therefore has a weaker stability guarantee than those app-facing surfaces.

## Hosts

A `Host` drives Sessions on a user's behalf. Its `run` method receives a `HostContext` containing the Agent Definition, staged Message, and optional Effect-native Transcript store. `createHostSession` creates the scoped Session for that context:

```ts
import { Effect, Stream } from "effect";
import { createHostSession, type Host } from "@mitome/core";

export const host: Host = {
  run: (context) =>
    Effect.runPromise(
      Effect.scoped(
        Effect.gen(function* () {
          const session = yield* createHostSession(context);
          yield* Stream.runForEach(session.runTurn(context.message), (event) =>
            event.type === "approval-required"
              ? event.deny("This Host does not permit Tool execution")
              : Effect.void,
          );
        }),
      ),
    ),
};
```

A Host may provide `unsupported(): string | undefined` when it only works in some environments. Mitome currently permits at most one interactive Host in a Mitome Definition.

## Providers

A Provider package uses `makeProvider(id, knownModelIds, credential, provision)` to bind its stable id and Model catalog to a function that returns an Effect `Layer` for the selected model. Keep credentials and provisioning behavior behind this constructor; the resulting Provider value exposes only its id and catalog hints.

The credential argument is either an environment-variable name, no credential, or an Auth capability descriptor:

```ts
import { Layer } from "effect";
import { LanguageModel } from "effect/unstable/ai";
import { makeProvider } from "@mitome/core";

declare const acmeLanguageModelLayer: (
  modelId: string,
) => Layer.Layer<LanguageModel.LanguageModel, unknown, never>;

const provider = makeProvider(
  "acme",
  ["small", "large"] as const,
  { capability: { module: import.meta.url } },
  (modelId) => acmeLanguageModelLayer(modelId),
);
```

An Auth capability module exports `authenticate` with the `AuthCapability["authenticate"]` contract. Hosts load that export from the descriptor's module URL to perform login or logout. The `authenticate` export on `@mitome/providers/openai-codex` is therefore Host plumbing; app code normally uses `mitome auth` rather than calling it directly.
