Mitome is prerelease. Its packages currently release together at one version; there is no compatibility promise across the accepted Effect-native redesign. Current source still implements the Promise-facing SDK and its Effect facade. The new API, export layout and storage contracts are not yet implemented; obsolete guides are removed rather than offered as a legacy surface.

Until 1.0, public functions, options, event fields and stored representations may change without a deprecation period. Published stored formats still need explicit versioning and migration decisions, not silent reinterpretation. See the [library plan](https://github.com/chenxin-yan/mitome/blob/main/docs/plans/effect-native-library.md) for proof and delivery gates.

## The Effect version

While Effect 4 is a release candidate, Mitome pins its exact version as a regular dependency. Code using Effect across the library boundary must match that version to preserve type/runtime identity. Check the repository catalog and installed dependency tree; do not copy a version from an unverified design sketch. [ADR-0046](https://github.com/chenxin-yan/mitome/blob/main/docs/adr/0046-pin-effect-as-a-regular-dependency-during-rc.md) revisits this rule when Effect 4 is stable.
