`@mitome/tui` is an interactive [Host](/docs/concepts#host) built on OpenTUI. Declaring it in the Mitome Definition is what activates it; installing the package alone does nothing.

```sh
mitome add @mitome/tui
```

```ts
import { defineMitome, fileTranscripts } from "@mitome/sdk";
import { tui } from "@mitome/tui";

export default defineMitome({
  agent,
  hosts: [tui()],
  transcripts: fileTranscripts(),
});
```

Run `mitome` to open an empty Session, or `mitome "first message"` to open it with the message staged in the input.

## Controls

| Keys          | Action                                                                                        |
| ------------- | --------------------------------------------------------------------------------------------- |
| `Enter`       | Insert a newline in the message box.                                                          |
| `Alt-Enter`   | Send the message.                                                                             |
| `Esc`         | Interrupt the running Turn; the Session stays usable. With the picker open, close the picker. |
| `Ctrl-O`      | Open the Transcript picker, listing stored Transcripts with update time and a preview.        |
| `Up` / `Down` | Move through the picker.                                                                      |
| `Enter`       | With the picker open, resume the selected Transcript into a new Session.                      |
| `Ctrl-N`      | Start a fresh Session without leaving the TUI.                                                |
| `Ctrl-C`      | Exit and release the Session.                                                                 |

The picker and `Ctrl-N` are available while the Session is idle; interrupt a running Turn first. Resuming seeds a new Session with the selected Transcript's Messages and records it as the parent of the new Transcript after the next completed Turn. Starting a new Session never modifies the previous Transcript.

Without `transcripts` in the Mitome Definition, `Ctrl-O` reports that persistence is not configured and touches no store. Add `transcripts: fileTranscripts()` to share Transcripts between the TUI and one-shot runs; see [Persistence](/docs/persistence).

## Streaming, Tools, and Approvals

Model text and Tool activity appear as the Turn runs. The TUI approves every `approval-required` event and shows `Tool <name> auto-approved`; only `preTool` Hooks can stop a Tool call here. If your Agent has Tools a person should confirm, see [Approvals](/docs/approvals#who-approves-by-default).

`Esc` interrupts the Turn. Nothing from it is committed to the Transcript; the write-only event log may retain the events emitted so far, as described under [Commit boundary](/docs/persistence#commit-boundary).

## Terminal requirements

The TUI needs a TTY on both stdin and stdout. When it does not have one, it reports `@mitome/tui requires an interactive terminal` and the CLI falls back to one-shot output; the fallback rules are described under [Hosts](/docs/hosts). The package requires Bun 1.3.14 or later, which the `mitome` binary provides.

Exiting disposes the view and closes the Session. Completed Turns are already saved at their commit boundary, so exiting while idle never rewrites a Transcript.
