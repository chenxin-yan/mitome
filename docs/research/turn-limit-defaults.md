# Should a Turn have a default limit?

Question from the owner's review of pull request #217: `@mitome/core` gives every Turn 64 Model generations and 256 Tool dispatches unless an Agent says otherwise (`firstPartyExecutionLimits`). Should the default be no limit, as in pi?

Short answer: defaults vary, and they follow who is expected to be watching less closely than it first looks. pi has no limit and no option for one; the Claude Agent SDK has none unless `maxTurns` is set, including for unattended single-shot `query()` calls; LangGraph's default is so high that it is a backstop, not a budget; OpenAI's Agents SDK and Vercel's AI SDK cap a run by default. Mitome's first target is a coding agent a person watches, where 64 Model calls is reached in ordinary work, so the default is no limit and an Agent that runs where nobody is watching sets `limits`.

| System             | Default                                                                                                                                                                                              | Evidence                                                                                                                                                                                               |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| pi 1.6.0           | No limit, and no option for one. The loop is `while (true)` around `while (hasMoreToolCalls \|\| pendingMessages.length > 0)`; it ends when the Model stops calling Tools, on abort, or on an error. | `.agent-sources/pi-mono/packages/agent/src/agent-loop.ts` lines 171-175; no match for a maximum of turns, steps or iterations in `packages/agent`, `packages/coding-agent`, `packages/ai` or pi's docs |
| Claude Agent SDK   | No limit: "`0` runs the session without a turn limit, the same as leaving the option unset" (`maxTurns`). Claude Code's `--max-turns` exists for non-interactive runs.                               | https://code.claude.com/docs/en/agent-sdk/configuration                                                                                                                                                |
| OpenAI Agents SDK  | A default cap: `max_turns: int \| None = DEFAULT_MAX_TURNS`, with a `max_turns` error handler. The constant's value was not on the fetched page.                                                     | https://openai.github.io/openai-agents-python/ref/run/                                                                                                                                                 |
| Vercel AI SDK      | "By default, `ToolLoopAgent` stops after 20 steps using `isStepCount(20)`."                                                                                                                          | https://ai-sdk.dev/docs/agents/loop-control                                                                                                                                                            |
| LangGraph (Python) | `recursion_limit`, counted in graph super-steps: 10,007 by default from version 1.1.4, and 10,000 between 1.0.6 and 1.1.3. A run that exceeds it raises `GraphRecursionError`.                       | https://docs.langchain.com/oss/python/langgraph/graph-api#recursion-limit                                                                                                                              |

What stops a runaway Turn where there is no limit: the person. pi and Claude Code are interrupted with a key; Mitome's terminal has the same (the interrupt control). `mitome run` ends on a signal within `--grace`, as a best effort: the timer runs in the same process, so a Tool that blocks the event loop holds back both the signal handler and the timer, and a hard deadline needs a supervisor outside the process.

Where nobody watches (a server, a chat Host, a schedule, `mitome run` in a script), a limit is the only brake inside the runtime. In Mitome that is the Agent's `limits`, set by whoever deploys it.
