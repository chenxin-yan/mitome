# Keep the CLI non-interactive

> Activation is superseded by explicit Host composition in [ADR-0039](0039-compose-hosts-explicitly-in-the-composition-root.md); the one-shot behavior remains.

> `mitome serve` is the one scoped exception to the one-shot rule: it runs the Definition's Channel Hosts ([ADR-0050](0050-discriminate-hosts-by-kind.md)) in the foreground until `SIGINT`/`SIGTERM`. Agent runs through `mitome [message]` stay one-shot.

> Auto-approval is withdrawn. One-shot output never waits for input, but an `approval-required` event is a request for a person ([ADR-0051](0051-let-the-agent-author-decide-tool-approvals.md)): with nobody present it is denied with a stable, Model-visible reason, the Turn continues, and the exit status is unchanged. `--yes` approves requests with `requirement: "tool"` for that invocation only; `"policy"` and `"predicate-error"` requests are still denied. Migration: scripts that relied on auto-approval of flagged Tools pass `--yes`, or the Agent author lists the Tools under `approvals.allow` (which also skips the Tool's own predicate; `--yes` does not). The TUI now prompts instead of approving.

Running an Agent through the CLI is fully non-interactive: `mitome "prompt"` starts one Session, runs one Turn, streams events to stdout, and exits. There is no prompt loop and no cross-invocation continuation. Pending Approvals are denied with a visible log line and a Model-visible reason, because no user is present mid-Turn to decide (originally they auto-approved; see the note above). A real Approval surface is a Host concern. This scopes only Agent runs — credential bootstrap (`mitome auth`, `mitome init`, ADR-0013) stays interactive because those are setup flows, not Sessions.

Interactivity belongs to a Host, not the CLI core: the `@mitome/tui` package supplies the interactive Host, activated by declaring it in the composition root's `hosts` ([ADR-0039](0039-compose-hosts-explicitly-in-the-composition-root.md)) — package presence alone has no activation semantics. With the Host declared, `mitome` and `mitome "prompt"` open the TUI with the prompt staged. `-p`/`--print` forces one-shot, a non-TTY stdout always falls back to one-shot so scripts never hang, and an unsupported terminal reports the reason and falls back to one-shot ([ADR-0039](0039-compose-hosts-explicitly-in-the-composition-root.md)). This keeps one CLI entry point, keeps Agent Definitions Host-agnostic (no UI choice lives in a Definition, and the TUI is not a Plugin), and keeps every non-CLI consumer free of interactivity code. A Definition-declared TUI field and a separate settings file were rejected: the first puts a UI choice inside the Agent Definition, the second invents a config surface for one boolean.
