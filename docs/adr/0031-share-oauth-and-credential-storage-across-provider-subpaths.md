# Share OAuth and Credential storage across provider subpaths

The RFC-generic half of Codex's auth lifecycle moves into `@mitome/providers/src/shared/`, amending ADR-0010 and ADR-0011 on ownership only: the storage format and the auth design they describe are unchanged, but neither is Codex's to own once a second OAuth Provider exists. `shared/credential-store.ts` owns `auth.json` — the cross-process lock, the atomic 0600 write, and the provider-keyed shape of ADR-0010 — and exposes it as a read plus a locked transaction scoped to one Provider key, not a read/write pair, because a rotating refresh token must be exchanged while the lock is held and one Provider must not see or clobber another's entry. `shared/oauth.ts` owns the PKCE flow of ADR-0011 — verifier and S256 challenge, loopback callback server, EADDRINUSE fallback to a pasted redirect URL, state validation, token exchange — as plain functions over an `OAuthConfig` record, deliberately not a factory or class, since a Provider's OAuth identity is data. A Provider keeps what is genuinely its own: its endpoints and client id as a config record, its Credential schema and validation, the claims it reads from an access token, any enrichment of the exchanged token, and its own user-facing remedies; the generic layer's errors name no CLI, because SDK consumers have no CLI.

`src/shared/` is named for what it is — the code more than one Provider subpath draws on, alongside the existing `shared/api-key-client.ts` — and it is not a public surface: nothing under it appears in `package.json` `exports`, and nothing may be added there. That rule is written here rather than carried by the directory name, which no longer implies it. Subpath exports plus `sideEffects: false` (ADR-0018) already keep this code out of API-key bundles, so no packaging change follows and no persistence SDK is published; a public storage surface is only justified if third-party Providers become a stated goal. This code remains Node/Bun-only under ADR-0021's confinement of filesystem APIs to the subpaths that need them, and nothing moves to `@mitome/core`.
