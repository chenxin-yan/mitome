# Consolidate provider adapters into @mitome/providers

Provider adapters ship as one package, `@mitome/providers`, with subpath-only exports (`@mitome/providers/openai`, `@mitome/providers/openai-compatible`, `@mitome/providers/openai-codex`) and no root barrel, replacing the earlier per-provider packaging. Subpath exports keep each provider tree-shakable, so consolidation costs nothing at bundle time; the accepted cost is install size, because one package has one dependency list and every consumer installs every provider's SDK dependency (`@effect/ai-openai`, `@effect/ai-openai-compat`, and whatever future providers add). This is acceptable while those dependencies are small pure-TypeScript packages — the Codex adapter needs none at all — and the decision should be revisited if a future provider would drag in a heavy SDK. The Codex transport and auth design remains in ADR-0011, and ADR-0017 requires an Agent Definition to select the protocol explicitly through its imported factory.
