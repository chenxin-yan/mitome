# Split instruction file paths from discovery

The first-party `instructionFiles` Plugin takes two deliberately asymmetric options instead of one overloaded argument: `paths` are explicit files resolved relative to the defining module and a missing file fails definition load, while `discover` takes bare filenames (e.g. `AGENTS.md`) searched from the process cwd upward to the git repository root (cwd only outside a repo), including every match outermost-first so nearer files carry higher salience, and silently skipping absent names because convention files are opt-in by presence. Reads are synchronous at definition-load time, when the Host has already established the correct cwd. We rejected inferring intent from the argument shape (a bare `instructions.md` is ambiguous between a sibling file and discovery, and the failure mode is silent wrong behavior). `mitome init` deliberately uses both modes: it pins the global XDG config `AGENTS.md` through `paths` and discovers project `AGENTS.md` files from the runtime working directory.
