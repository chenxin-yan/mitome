# Publish a Promise-first SDK as the default surface

The MVP adds `@mitome/sdk` as the default face of Mitome: `mitome init` templates and primary documentation import the SDK, while `@mitome/core` remains the Effect-native runtime and power-user surface. The SDK owns the complete ordinary-user Interface — `defineAgent`, `definePlugin`, `tool`, and `withSession` — and adapts plain async authoring immediately into canonical Core values. It implements no parallel Session loop, Tool execution, history, or Hook machinery, and no SDK/Core conversion functions exist: SDK builders return canonical Core values, so SDK-authored and Effect-authored Plugins mix freely in one Definition. Plugin authoring has full parity — every MVP Hook plus one `setup`/`dispose` resource pair per Plugin, adapted into scoped acquisition (acquire in Definition order, dispose in reverse, a Plugin's resource visible only to its own Tools and Hooks). An SDK Tool declares input and output schemas only; a thrown or rejected handler becomes a generic typed failure result to the model and the Turn continues, while custom failure schemas remain Core-only until demanded. `withSession` owns Session allocation and cleanup (no bare Promise `createSession`); `session.prompt()` returns an `AsyncIterable` of Turn events; Turn failures throw stable tagged `Error` subclasses with the original cause attached; breaking iteration early interrupts the Turn, discards its incomplete output, and leaves the Session reusable; handlers and Hooks receive an `AbortSignal` wired to Core interruption. The SDK and provider packages declare exact lockstep `@mitome/core` peer dependencies while Effect remains beta. This supersedes ADR-0009's single-package "SDK" clause and the no-Promise-interface clauses of ADR-0001 and ADR-0003; the CLI continues to consume Core directly.
