# @mitome/channels

First-party Channel Hosts for Mitome Agents. The package has no root import; each Channel ships on its own subpath (`@mitome/channels/http` and `@mitome/channels/telegram` are planned) and takes its Route store through its factory options.

```sh
npm install @mitome/sdk @mitome/channels
```

Hosts and Channels are described under [Hosts](https://mitome.sh/docs/hosts).
