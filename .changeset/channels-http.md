Add `@mitome/channels`, the package of first-party Channel Hosts, with its first Channel at `@mitome/channels/http`. `http({ auth, routes, approvals? })` is a `kind: "channel"` Host exposing `handle` only: `POST /conversations/:id/turns` with `{ message, model? }` streams the Turn as Server-Sent Events in a versioned envelope `{ v: 1, turnId, event }` whose events follow the public `TurnEvent` vocabulary. `bearer({ token: principal })` is the built-in `Authenticator`; authentication runs before any store or Provider call, and the Route key is `(name, principal, conversation)`, so a client-chosen id is never authorization. An overlapping Turn on one Route is `409`, a client disconnect interrupts the Turn and closes its Session, and a failure after the stream started ends it with one sanitized `error` frame. Pending Approvals are denied by default with a stable Model-visible reason; `approvals: "interactive"` keeps them pending for `POST /turns/:turnId/approvals/:approvalId`, which authenticates the caller, requires the Turn's own principal (`403` otherwise), answers `404` for stale or duplicate ids without re-executing, and denies after `approvalTimeoutMs` (default five minutes). There is no channel auto-approve mode; unattended runs go through the Agent's `approvals.allow`.
