"@mitome/transcripts": minor
---

Add `@mitome/transcripts`, which keeps conversations in files. `jsonlTranscripts()`, from `@mitome/transcripts/jsonl`, is a Layer that provides `Transcripts` to a Configuration (`Mitome.make({ agent, providers, model, provide: jsonlTranscripts() })`) and requires nothing: it binds Node's file system, which Bun also runs. Each conversation is one append-only JSONL file, `<id>.jsonl`, under `transcripts` in the state directory (`directory` chooses another), created readable by its owner only on POSIX systems (`0700` directories, missing ones above it included, and `0600` files; on Windows these modes set no owner-only ACL). An append refuses, writing nothing, an Entry the file could not give back: a repeated id, a parent it does not hold, Messages that are not plain data by the kernel's rule (`isPlainData` from `@mitome/core`, JSON as Effect's `Schema.Json` defines it), a record field whose value is `undefined` included, which a Session has already dropped, or plain data the codec cannot read back once written. Of plain data, JSON drops only the sign of negative zero. Every append and move takes the conversation's lock file, refuses with a `conflict` when another writer has moved the stored position, and writes and syncs before it answers. A last line left incomplete by a crash is ignored and overwritten; a file of an unknown version or with a malformed line fails to open with `TranscriptError`. `latest(scope)` is the conversation with that scope written most recently; `open(id)` of an id that names none is `undefined`. Building the Layer fails when no state directory can be resolved and no `directory` is given.
