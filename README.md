# Mitome

## Installation

```sh
npm install @mitome/sdk @mitome/providers
```

Import Promise-first APIs from `@mitome/sdk` or Effect-native APIs from `@mitome/sdk/effect`. To install the CLI, see [`@mitome/cli`](packages/cli/README.md).

## Development

Install [mise](https://mise.jdx.dev/getting-started.html) and activate it in your shell, then run:

```sh
mise trust
mise install
bun install
```

Run the CLI with `bun run dev:cli` or the docs site with `bun run dev:docs`.
