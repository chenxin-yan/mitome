# Mitome

## Installation

```sh
npm install @mitome/sdk @mitome/providers @mitome/plugins
```

Import Promise-first APIs from `@mitome/sdk` or Effect-native APIs from `@mitome/sdk/effect`.

## Development

Install [mise](https://mise.jdx.dev/getting-started.html) and activate it in your shell, then run:

```sh
mise trust
mise install
bun install
```

Run the CLI with `bun run dev:cli` or the docs site with `bun run dev:docs`.
